🏦 Northwind Bank — AI Account Assistant

Agent identity · RFC 8693 token exchange · DPoP · Kong PDP enforcement (MCP + API)

How the agents & services interact

Alice authorises a principal agent, which delegates to a task agent — the token exchange nests the actor chain at each hop. Both gateways (PEP #1/#2) and the token exchange consult Ping Authorize (the PDP) for a PERMIT/DENY. Nodes light up as a run progresses.

Token Exchange RFC 8693
Swaps principal + agent tokens for one delegated token carrying both — delegation, not impersonation.
DPoP RFC 9449
Sender-constraint: token bound to the agent's key (cnf.jkt); each call carries a fresh signed proof.
RAR RFC 9396
authorization_details — fine-grained grant (this payment, this cap) beyond coarse scopes.
AuthZEN OpenID
Standard request/response for asking a PDP "can this subject do this action on this resource?"
MCP
Model Context Protocol — how the agent discovers and calls the bank's tools (JSON-RPC).
