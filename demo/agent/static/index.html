What am I looking at? — actors & protocols
Principal
The human the agent acts for (Alice, sub in the token).
Agent
The AI software taking the action (act.sub in the token) — a distinct identity from the human.
Agent Operator
The org that runs the agent; the OAuth client_id.
Token exchange (RFC 8693)
Swaps the principal's token + the agent's token for a delegated token carrying both — delegation, not impersonation.
DPoP (RFC 9449)
Sender-constraint: the token is bound to the agent's key (cnf.jkt); every call carries a fresh signed proof.
RAR (RFC 9396)
authorization_details — fine-grained grant (this payment, this cap) beyond coarse scopes.
PEP
Policy Enforcement Point — the Kong gateway that intercepts each call.
PDP
Policy Decision Point — Ping Authorize (via the AuthZEN adapter) that returns PERMIT/DENY.
